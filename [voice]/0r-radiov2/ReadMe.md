# Description

- Fivem QB Framework, Radio script, pma-voice or saltychat

# Information

- Make sure that the value of 'fxmanifes.lua dependency' and 'Config.VoiceSystem' are the same.
- Don't forget to edit the config file
- Make sure you are using the latest version of pma-voice.
- Make sure the pma-voice has isPlayerMuted export
- The default radio item name is "radio2". You can edit it from the "shared/config.lua" file.
- Make sure that you have added the item on the server.
- Feel free to reach out to us if you have any problems.
