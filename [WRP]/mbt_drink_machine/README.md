**Malibù Tech** is glad to present a simple, but good looking script to make your vending machine pretty unique! 


## Features


 - ESX compatible (Tested with ESX Legacy)
 - QB compatible
 - Easily config script with your own event to fit your needs
 - Interactable props can be added
 - Choose between markers and target system
 - Use your own notifications
 - Add custom bottle image
 - Add custom logo image
 - Customizable labels
 - Optimized for low CPU usage
 - Easy configuration with explanatory comments
 - Immersive experience thanks to SFX
